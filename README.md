## Orden de Estudio Sugerido

1. **U00** — Mediciones, incertezas, vectores, unidades del SI
2. **U01** — Cinemática del punto material
3. **U02** — Dinámica del punto material
4. **U03** — Trabajo y Energía
5. **U04** — Sistema de partículas, Torque y Momento Angular
6. **U05–U07** — Cuerpo Rígido (Cinemática, Dinámica, Dinámica Impulsiva)
7. **U08** — Hidrodinámica
8. **U09** — Ondas Mecánicas
9. **U11 (Superposición)** — Batidos y Ondas Estacionarias
10. **U10** — Óptica Geométrica
11. **U11 (Óptica Física)** — Interferencia y Difracción

## Cómo descargar los materiales

### Opción 1 — Descargar todo como ZIP (más fácil, sin instalar nada)

1. Ir a la página principal del repositorio en GitHub
2. Hacer clic en el botón verde **`<> Code`**
3. Seleccionar **"Download ZIP"**
4. Descomprimir el archivo descargado

### Opción 2 — Descargar un archivo individual

1. Navegar hasta el archivo dentro del repositorio
2. Hacer clic en el nombre del archivo para abrirlo
3. Hacer clic en el botón **"Download raw file"** (ícono de descarga, arriba a la derecha)

### Opción 3 — Clonar con Git (para mantenerlo actualizado)

Si tenés Git instalado, desde la terminal:

```bash
git clone https://github.com/TU_USUARIO/TU_REPO.git
```

Para actualizar cuando haya cambios nuevos:

```bash
git pull
```
